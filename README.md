# 📋 CollabTask

Aplicativo web para organização e gerenciamento de projetos.

## 📚 Descrição

Aplicação web desenvolvida para facilitar a organização e o gerenciamento de projetos colaborativos. Com uma interface intuitiva e diversas funcionalidades, permite que equipes acompanhem o progresso de projeto, através de algumas atividades.

## 🚀 Funcionalidades

- Criação e gerenciamento de projetos
- Atribuição de tarefas a membros da equipe
- Monitoramento do progresso das tarefas
- Compartilhamento de arquivos e documentos
- Comunicação em tempo real entre os membros da equipe

## 🛠️ Construído com

* [React](https://reactjs.org/) - Biblioteca de JavaScript usada no front-end
* [PHP](https://www.php.net/) - Linguagem usada para construção da API no back-end
* [MySQL](https://www.mysql.com/) - Sistema de gerenciamento do banco de dados

## 📦 Instalação

Para instalar e rodar o projeto localmente:

1. Clone o repositório:
    ```bash
    git clone https://github.com/Evy8882/CollabTask.git
    ```
2. Navegue até o diretório do projeto:
    ```bash
    cd CollabTask
    ```
3. Instale as dependências do front-end:
    ```bash
    npm install
    ```
4. Configure o servidor PHP e o banco de dados MySQL conforme necessário.

## 🗂️ Estrutura do Projeto

- `/src` - Código fonte do front-end em React
- `/api` - Código fonte da API em PHP
- `/database` - Scripts SQL para criação do banco de dados
